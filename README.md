# 🔗 URL Shortener API

A full-stack URL Shortener application built using Node.js, Express.js, MongoDB Atlas, and vanilla HTML/CSS/JavaScript.

Users can:
- Shorten long URLs
- Create custom meaningful short links
- Redirect using short URLs
- Track click counts
